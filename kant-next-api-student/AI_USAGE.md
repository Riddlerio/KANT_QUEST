# AI 사용 기록

AI는 개념 질문과 직접 작성한 코드의 디버깅에만 사용할 수 있습니다. 사용하지 않았다면 아래에 `사용하지 않음`이라고 적습니다. 사용량을 늘릴 필요는 없습니다.

| 허용되는 도움 | 예시 |
|---|---|
| 개념 이해 | HTTP 404와 422의 차이, await의 의미를 다른 예시로 설명해 달라고 질문 |
| 자신의 코드 디버깅 | 직접 작성한 짧은 함수와 오류를 보여 주고 원인과 확인 방법을 질문 |

과제 전체 풀이, TODO의 완성 코드, 참고 답안을 요청하지 않습니다. 디버깅 답변도 이해한 원인과 수정 내용을 자신의 말로 기록하고 다시 실행합니다. API 키, `.env`와 인증 헤더를 질문에 포함하지 않습니다.

## 사용 여부

- 사용 여부: 사용
- 사용한 도구: 챗지피티

## 도움 기록

도움을 받은 건마다 표의 행을 추가합니다. 대화 전문보다 질문과 직접 확인한 결과를 구체적으로 적습니다.

| 단계/함수 | 직접 시도한 내용과 문제 | 질문 요약 | 받은 설명 | 내가 수정하거나 확인한 내용 | 재실행 결과 |
|---|---|---|---|---|---|
| `QueryRequest`, `QueryReply` | 모델 필드를 작성한 뒤 여러 단계에서 검증 오류가 발생했다. | 실패 원인과 필드명 오타를 확인해 달라고 요청했다. | 요청·응답에서 사용하는 이름이 모델 선언과 정확히 같아야 한다는 설명을 받았다. | `need_human`을 `needs_human`으로 수정하고, `documents_id`의 정확한 이름이 `document_ids`임을 확인했다. | 답변·모델 연결·재시도 검사는 통과했다. 마지막 `document_ids` 수정 후 결과는 미확인이다. |
| `find_document` 및 설명 주석 | GET/POST의 입력 위치와 404, 422의 의미를 몰라 주석 작성이 어려웠다. | 없는 ID와 잘못된 입력을 어떻게 구분하는지 질문했다. | 이 과제의 GET 조회는 경로의 ID를, POST 등록은 JSON 본문을 사용한다. 없는 문서는 404, 입력 형식 오류는 422로 구분한다는 설명을 받았다. | 입력 위치와 오류 종류의 차이를 주석으로 정리했다. | 허용 ID의 등록과 조회 검사를 통과했다. |
| `category` 필드 선언 | 모델 필드를 작성하면서 `:`와 `=` 중 무엇을 사용해야 하는지 헷갈렸다. | 자료형 선언과 값 대입의 차이를 질문했다. | `:`는 자료형을 지정하고 `=`는 값이나 기본값을 대입하며, `category: Literal[...]`로 허용 문자열을 제한한다는 설명을 받았다. | `category`의 자료형과 문서용·답변용 허용 범위를 확인했다. | 문서 모델과 답변 모델 검사를 통과했다. |
| `normalize_releases`의 플래그 검사 | `any(...)` 안에서 `key`가 어디서 오는지와 값을 조회하는 방법이 헷갈렸다. | `for key in ("draft", "prerelease")`와 `item.get(key)`의 동작을 질문했다. | `key`에 두 문자열이 차례로 들어가고, `item.get(key)`로 해당 값을 조회한다. 하나라도 boolean이 아니면 `any(...)`가 참이 된다는 설명을 받았다. | 반복 변수와 딕셔너리 조회의 관계를 이해하고 플래그 검사 조건을 확인했다. | boolean이 아닌 `draft`, `prerelease`를 거부하는 검사를 통과했다. |
| `register_document`의 중복 URL 검사 | 리스트 컴프리헨션으로 중복 URL을 확인하려다가 비교 조건을 구성하지 못했다. | 저장된 문서를 순회하며 URL 중복을 확인하는 방법에 대한 가이드를 요청했다. | `store.values()`로 문서를 순회하고 URL 비교 결과를 `any(...)`에 전달하면 된다. `any` 안의 표현식은 리스트를 만들지 않는 제너레이터 표현식이라는 설명을 받았다. | `any(s.source_url == document.source_url for s in store.values())`의 순회와 비교 조건을 확인했다. | 중복 URL 검사만을 대상으로 한 별도 재실행 결과는 기록하지 않았다. |
